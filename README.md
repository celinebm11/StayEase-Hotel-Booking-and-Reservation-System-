# StayEase: Hotel Booking and Reservation System

## 1. Project Title
**StayEase: Hotel Booking and Reservation System**

## 2. Project Description
StayEase is a Java-based Hotel Booking and Reservation System designed to make hotel room reservations and management easier. It allows guests to search for available rooms, check prices, make reservations, process simulated payments, and manage their bookings. Administrators can manage rooms, monitor reservations, handle guest check-ins and check-outs, and generate reports.

## 3. Problem Being Addressed
Managing hotel reservations manually can be time-consuming and may lead to booking errors, inaccurate room availability, and difficulties tracking payments and reservations.

StayEase aims to provide a simple system that organizes hotel bookings, room information, and payment records in one application. It helps reduce manual work and makes reservation management more organized.

## 4. Project Objectives

**General Objective:**

To develop a Java-based application that simplifies hotel room reservations and management through an organized and user-friendly console system.

**Specific Objectives:**
- Allow guests to register and log in to the system.
- Display available rooms based on dates, guest count, and room type.
- Calculate booking costs, taxes, and applicable discounts.
- Provide simulated payment options.
- Allow guests to view and cancel their reservations.
- Allow administrators to manage rooms and reservations.
- Generate receipts and display hotel occupancy and revenue reports.
- Demonstrate the use of object-oriented programming concepts in Java.

## 5. Target Users

**Guests**
- Register and log in.
- Search for available rooms.
- View room prices and details.
- Make reservations and payments.
- View and cancel bookings.

**Administrators**
- Manage room information.
- Monitor room availability.
- View guest reservations.
- Handle guest check-ins and check-outs.
- Record payments and generate receipts.
- View occupancy rates and total revenue.

## 6. Main Features

- **Role-Based Login:** Provides different menus for guests and administrators.
- **Room Search:** Allows guests to search for available rooms based on dates, number of guests, and room type.
- **Billing and Discounts:** Calculates the total booking cost, including 12% tax and applicable discounts.
- **Payments and Bookings:** Supports simulated Cash, Card, and GCash payments.
- **Booking Management:** Allows guests to view and cancel reservations.
- **Admin Tools:** Allows administrators to manage rooms, process check-ins and check-outs, and record payments.
- **Reports and Receipts:** Generates text receipts and displays occupancy rates and total revenue.

## 9. OOP Concepts Demonstrated

StayEase demonstrates the following Object-Oriented Programming concepts:

1. **Classes and Objects** – Uses classes such as User, Guest, Admin, Room, Booking, Payment, Discount, and Receipt to organize the system.
2. **Encapsulation** – Protects important data using private attributes and controlled access through methods.
3. **Inheritance** – Uses Guest and Admin as subclasses of the User class.
4. **Polymorphism** – Allows different classes to implement their own versions of methods such as showMenu(), calculateDiscount(), and processPayment().
5. **Abstraction** – Uses abstract classes and interfaces to define common behaviors.
6. **Exception Handling** – Uses try-catch blocks and custom exceptions to handle invalid inputs and errors.
7. **Arrays/Data Handling** – Uses ArrayList to store and manage room and booking information.

## 12. Known Limitations

- **Console-Based Only:** The application runs in the console and does not have a graphical user interface (GUI), website, or mobile application.
- **Simulated Payments:** Cash, Card, and GCash payments are simulated and do not connect to real banks or online payment applications.
- **Simple Login System:** Guests log in using only their names without password encryption or email verification.
